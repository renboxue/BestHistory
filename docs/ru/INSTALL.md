# Установка — BestHistory

Установите BestHistory из официального Chrome Web Store или Firefox Add-ons. Проверьте издателя, добавьте расширение и откройте его с панели браузера. Версии из магазина обычно обновляются автоматически.

- [Установить для Chrome](https://chromewebstore.google.com/detail/besthistory/ehcgfdgajgkkmelcjipahckmgjfdcajb)
- [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/besthistory/)

## Приватная история

Для необязательной записи посещений в режиме инкогнито с Pro необходимо самостоятельно включить разрешение в настройках расширений Chrome.
