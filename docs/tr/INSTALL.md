# Yükle — BestHistory

BestHistory'yi resmi Chrome Web Store veya Firefox Add-ons üzerinden yükleyin. Yayıncıyı doğrulayın, uzantıyı ekleyin ve tarayıcı araç çubuğundan açın. Mağaza sürümleri genellikle otomatik güncellenir.

- [Chrome'a ekle](https://chromewebstore.google.com/detail/besthistory/ehcgfdgajgkkmelcjipahckmgjfdcajb)
- [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/besthistory/)

## Özel geçmiş

Pro ile gizli mod ziyaretlerini saklamak isterseniz Chrome uzantı ayarlarından gizli mod iznini açıkça kendiniz vermelisiniz.
