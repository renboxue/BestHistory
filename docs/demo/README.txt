BestHistory D1-R3 (simplified AI entrypoint)
============================================

Local scripted demo only; fictional history data. No AI network service, real browser-history reading, or persistent/encrypted private data.

Traditional search remains the main-page search field. The top "Open AI Recall · Demo" button opens the AI Recall modal, auto-fills the only supported fictional memory, and immediately plays the simulated thinking animation (about 1.5 seconds) and scripted matching result. The "Replay example" control plays it again. No more sample strip, fill button, second AI launch button, or AI search mode for the ordinary history list.

Private Mode is unchanged from D1-R2. Use its sidebar entry for demo-only setup, lock/unlock and Private Sites filtering. Password is in page memory only; nothing is encrypted.

This build does not modify the production extension, GitHub, Supabase, Paddle, or any online deployment.
