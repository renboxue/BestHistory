# Cài BestHistory Beta trên Chrome

[← BestHistory](README.md) · [Tất cả ngôn ngữ](../LANGUAGES.md)

Trước khi có mặt trên Chrome Web Store, Beta được phân phối qua GitHub Releases.

Tải: **https://github.com/renboxue/BestHistory/releases/tag/v0.1.0-beta**

File: `BestHistory-v0.1.0-beta-chrome.zip`

1. Giải nén ZIP vào thư mục bạn sẽ giữ lại.
2. Mở `chrome://extensions/`.
3. Bật **Developer mode**.
4. Chọn **Load unpacked**.
5. Chọn thư mục BestHistory đã giải nén.
6. Có thể ghim BestHistory từ menu extension.
7. Bấm icon trên toolbar để mở trang chính.

## Ẩn danh / Chế độ riêng tư
Để lưu lượt truy cập ẩn danh: `chrome://extensions/` → Details của BestHistory → bật **Allow in Incognito**. Quyền này là tùy chọn và BestHistory không thể tự bật thay bạn.

## Cập nhật thủ công
Beta mới có thể yêu cầu thay thư mục đã giải nén và reload extension. Nên tạo `.bhbackup` trước khi thử cập nhật sớm.
