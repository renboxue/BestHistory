# Eine früher besuchte Website wiederfinden, auch ohne ihren Namen

Sie erinnern sich an den Zweck einer Website, aber nicht an ihren Namen? Diese Anleitungen zeigen, wie Sie vorhandene Browserverläufe gezielt durchsuchen.

## Mit den vorhandenen Hinweisen beginnen

Öffnen Sie <code>chrome://history/</code> und suchen Sie nach einem Titelteil, einer Domain oder dem Verwendungszweck wie „PDF umwandeln“. Probieren Sie mehrere Begriffe: Der Chrome-Verlauf durchsucht nicht automatisch den vollständigen Text aller Seiten.

## Zuerst die Website, dann die Einzelseite finden

Viele Besuche derselben Website erscheinen normalerweise als lange Liste. BestHistory fasst Besuche nach Website zusammen und zeigt die einzelnen Seiten erst bei Bedarf an.

## Eigene Merkhilfen festhalten

Ergänzen Sie Tags oder Notizen wie „Seite zum Umwandeln von PDFs“. So können Sie die Website später auch dann finden, wenn Ihnen ihr offizieller Name wieder entfallen ist.

## Grenzen der Wiederherstellung beachten

Gelöschte oder nie gespeicherte Besuche kann BestHistory nicht neu erzeugen. Das Tool hilft dabei, vorhandene Einträge wiederzufinden und zu ordnen.
