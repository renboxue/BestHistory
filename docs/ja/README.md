## はじめに：なぜ BestHistory を作ったのか

BestHistory は、私自身が日常的に困っていたことを解決するために、一人の個人開発者として作り始めた小さなツールです。

数日前に便利なサイトを使ったのに、必要になったときには名前を思い出せない。「どこかのサイトで見た」ことだけ覚えていて、具体的なページは分からない。二度と見つけられないのが怖くて、タブやウィンドウを大量に開きっぱなしにし、よく使うサイトは固定し、さらにブックマークにも入れる。気づけば履歴、固定タブ、ブックマーク、閉じられないページが全部増えているのに、昔使ったサイトを探すのは相変わらず大変でした。

そこで気づいたのは、私が欲しかったのは「もっときれいな履歴一覧」ではないということです。

人の記憶に近い形で探したかったのです。

**ページタイトルや訪問日を忘れても、「どんなサイトだったか」「何に使ったか」は意外と覚えています。**

そこから BestHistory が生まれました。

> **「あとで見つからないのが怖い」だけで開き続けているタブを、安心して閉じられるようにする。**  
> 本当に必要になったとき、BestHistory がもう一度そこへ連れていけることを目指しています。

まだとても初期段階の個人プロジェクトです。同じ悩みを少しでも解決できたなら本当にうれしいです。使いやすいところ、使いにくいところ、次に何を解決してほしいかもぜひ教えてください。

## 普通のブラウザー履歴と何が違う？

### 1. 何万件ものページより、まず「サイト」を見る

これが BestHistory の中心です。

通常の履歴はすべてのページ訪問を一列に並べます。同じサイトで何十ページも開けば、そのサイトだけで履歴が埋まってしまいます。

BestHistory は最初に履歴を**ウェブサイト単位**でまとめます。最近使ったサイト、よく使うサイト、最後にいつ見たか、そのサイト内で過去にどのページを開いたかを確認できます。

### 2. いろいろな並べ方で、本当に使っているサイトを見つける

- **最近** — 直近で使ったもの
- **よく使う** — 繰り返し利用しているサイト
- **名前順** — 名前を覚えているとき
- **固定** — 大事なサイトを先頭へ
- **未整理 / ごみ箱 / プライベートサイト** などの状態別表示

### 3. 自分のタグで整理する

あるサイトが他の人には「ツール」でも、自分には「仕事」かもしれません。「デザイン」「AI」「また使う」が同時に当てはまることもあります。

BestHistory は**カスタムタグ**と複数タグをサポートします。完璧な分類を作るためではなく、数か月後に「だいたい何に使ったサイトか」しか覚えていないときの、もう一つの道しるべです。

### 4. 同じサイトをまとめる、すっきりしたタイムライン

「昨日の午後、何を見ていたんだろう？」という振り返りも必要です。

BestHistory のタイムラインでは、同じサイトで連続して開いたページをひとつにまとめ、必要なときだけ展開できます。

<p align="center"><img src="../../assets/screenshots/timeline.webp" alt="BestHistory 折りたたみタイムライン" width="100%" /></p>
<p align="center"><sub>同じサイトのページをまとめることで、タイトルの壁ではなく「閲覧の流れ」として見返せます。</sub></p>

### 5. 自分だけが分かればいい説明を書ける

サイト名を見ても用途を思い出せないことがあります。そこで、自分用の名前やメモを付けられます。

> 「前に PDF を画像に変換したサイト」
>
> 「子ども向けイラストの参考にしたサイト」
>
> 「過去価格を調べられる小さなツール」

こうした自分の言葉も検索対象になります。公式タイトルより、自分の記憶に近いことがあります。

## プライベートモード：覚えておきたい。でも人には見られたくない履歴

すべての履歴が「残したくない」わけではありません。ただ、普通の履歴に混ざって他の人に簡単に見られたくないものもあります。

BestHistory の **プライベートモード（Pro）** は、プライベートな URL、ページタイトル、訪問記録を端末上で暗号化して保存します。設定したプライベートパスワードを入力したときだけ確認できます。

また、ユーザーが明示的に許可した場合、シークレットウィンドウでの訪問も暗号化して保存できます。通常のサイト一覧には混ざらず、プライベートモードがロックされている間は直接表示されません。

> **普通の履歴には置きにくいサイトも、BestHistory なら静かに覚えておけます。**

プライベートデータは端末に残り、BestHistory のサーバーはプライベート URL、タイトル、履歴、パスワードを保存しません。

---

## 検索、固定、ごみ箱

検索はドメインだけではありません。サイト、ドメイン、タグ、メモ、ページタイトルを使って探せます。サイト名を忘れていても、「そこで何を見たか」を少し覚えていれば再発見できる可能性があります。

よく使うサイトは固定できます。今は見たくないサイトは、すぐ削除せず**ごみ箱**へ移動できます。あとで戻すことも、完全に削除することもできます。

「今は片づけておく」ことを普通の選択肢にしたいと思っています。

---

## バックアップ、復元、ブラウザー間の移行

BestHistory の整理データは基本的にローカル保存です。単一の `.bhbackup` ファイルを書き出し、別の PC、別のインストール、別のブラウザーへ移行・マージできます。

復元は現在のデータを全部上書きするのではなく、安全なマージ方式です。プライベートモードのデータはバックアップ内でも暗号化されたままで、復元には元のプライベートパスワードが必要です。

> 現時点の「ブラウザー間同期」は、ローカルバックアップによる移行とマージを意味します。完全な閲覧履歴をクラウドへアップロードしてリアルタイム同期する仕組みではありません。

BestHistory をまず**ローカルファースト**のツールにしたいからです。

---

## プライバシー、Free、Pro

BestHistory のサーバーは、閲覧履歴、URL、ページタイトル、タグ、メモ、検索内容、プライベート履歴、暗号鍵、`.bhbackup` の内容を保存しません。

ログインした場合、サーバーが扱うのは主にアカウント、認証、Free / Trial / Pro の権利情報です。詳しくは [PRIVACY.md](PRIVACY.md) をご覧ください。

ローカルの主要機能は**ログインなしで継続利用できます**。Beta 期間中、新規登録アカウントには現在 **30 日間の Pro トライアル**があります。現在の主な Pro 機能はプライベートモードです。

## まだ始まったばかりです

BestHistory を作り始めた理由は、「閉じたら二度と見つからない気がして、タブを閉じられない」ことでした。

今は、閉じたサイトをもう一度見つける手助けができます。これからも同じ中心課題の周りで、不要なタブを安心して閉じられること、本当に使ったサイトをもっと楽に整理できることを考えていきたいです。

もし BestHistory が役に立ったら、⭐ Star、Issue、日頃どのように履歴やブックマークや大量のタブを管理しているかのフィードバックをいただけるとうれしいです。公開しにくい内容は **besthistory@126.com** へどうぞ。

公開 Issue には、プライベート URL、パスワード、プライベート履歴、完全なバックアップなどの機密情報を含めないでください。
