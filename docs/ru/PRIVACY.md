# Политика конфиденциальности BestHistory

_Последнее обновление: 2026-08-20_

[← BestHistory](README.md) · [Все языки](../LANGUAGES.md)

BestHistory — local-first расширение для организации истории браузера.

## Данные просмотра
История, посещённые URL, заголовки страниц, метаданные сайтов, метки, заметки, поисковый ввод и записи Приватного режима обрабатываются на устройстве и не загружаются на сервер аккаунтов BestHistory.

## Аккаунт и права
При входе BestHistory использует инфраструктуру аккаунта, чтобы определить Free / Trial / Pro. Могут храниться ID аккаунта, e-mail и метаданные аутентификации, предпочтительный язык, статус/срок пробного периода или подписки, а в будущем — идентификаторы платёжного провайдера.

## Приватный режим
Приватные URL, заголовки и посещения шифруются на устройстве. Приватный пароль и расшифрованные приватные данные не отправляются на сервер.

## Резервные копии
Резервные копии создаются локально и автоматически не загружаются. Приватные записи остаются зашифрованными; не следует считать, что весь обычный исторический раздел файла зашифрован целиком.

## Сторонние сервисы
BestHistory использует Supabase для аутентификации/прав и Amazon SES для писем аутентификации. Эти сервисы обрабатывают только необходимое для аккаунта и доставки почты, а не историю браузера.

## Удаление
Локальные данные можно удалить из расширения. Выход удаляет локальную сессию, но не предназначен для удаления локальных данных организации. Удаление аккаунта может быть расширено во время Beta.
