# BestHistory v1.1.0

**Release date:** 2026-10-09

BestHistory v1.1.0 is the complete 18-language Chrome internationalization update.

## Highlights

- Added Chrome official `_locales` metadata for all 18 supported languages.
- Added `default_locale: en` and localized manifest name, description, and action title.
- Audited all 511 runtime i18n message keys across 18 languages.
- Verified payment/subscription UI localization, including Dodo Payments, subscription management, cancellation/renewal status, and Pro entitlement copy.
- Removed stale Paddle Sandbox / Paddle.js test wording from the active payment UI.
- Kept Google sign-in and the Chrome `identity` permission.
- Preserved local-first browsing history, Private Mode, AI Recall, AI Organization, backup/restore, and Pro entitlement behavior.
