# BestHistory v0.1.0 Beta

BestHistory की पहली public Beta।

BestHistory browsing history को endless page list की जगह **websites** के आसपास organize करता है। यह मेरी अपनी समस्या से शुरू हुआ: useful site दोबारा न मिले इसलिए मैं बहुत सारे tabs/windows खुले रखता, pin और bookmark करता रहता था।

इस Beta में website auto-grouping, Recent/Most visited/Name/Pinned views, custom tags, site names और notes, collapsible timeline, search, Trash, `.bhbackup`, 18 UI languages, Pro Private Mode और explicit permission के बाद optional encrypted Incognito capture शामिल हैं।

यह उस bug को भी fix करता है जिसमें BestHistory लंबे समय तक खुला रहने पर websites और timeline latest history से update नहीं होते थे।

## Privacy
BestHistory local-first है। Server history, URLs, titles, tags, notes, searches, private records, encryption keys या `.bhbackup` content store नहीं करता।

## Install
`BestHistory-v0.1.0-beta-chrome.zip` download और extract करें, `chrome://extensions/` खोलें, Developer mode चालू करें और “Load unpacked” चुनें।
