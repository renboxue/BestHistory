# 名前を忘れたサイトを数か月後に探す方法

以前使ったサイトの名前を忘れても、使い道やページの一部は覚えていることがあります。残っている履歴から探す方法を紹介します。

## 覚えている手がかりから始める

Chrome で <code>chrome://history/</code> を開き、タイトルの一部、ドメイン、使ったサービス名などを検索します。「PDF 変換」「価格比較」のように、用途を表す語も試してください。Chrome の履歴検索はページ本文の全文検索ではありません。

## ページではなくサイト単位で探す

同じサイトを何度も開くと履歴に多数の項目が並びます。BestHistory は訪問記録をサイト別にまとめ、サイトを特定してから個々のページを確認できます。

## 自分の言葉でメモを残す

見つけたサイトに「前にPDFを画像へ変換したサイト」といったメモやタグを付けておけば、名前を再び忘れたときの手がかりになります。

## 記録がない場合は戻せない

削除された履歴や、そもそもブラウザに保存されなかった訪問記録を BestHistory が復元することはできません。残っている記録を探しやすくするツールです。
