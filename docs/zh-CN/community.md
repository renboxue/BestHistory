# 博学智伴社区

**BestHistory 是博学智伴（Zhiban）旗下 Best Series 产品。**

博学智伴社区用于连接 BestHistory 以及未来其他 Zhiban 产品的用户。

你可以在这里：

- 讨论 BestHistory 和其他 Best Series 产品；
- 提交 Bug 和功能建议；
- 参加 Beta 测试和 Early Access；
- 获取重要版本和产品公告；
- 参与 Zhiban 下一款产品的改进和共创。

## 加入 Discord

官方 **Zhiban Community / 博学智伴社区** Discord 服务器现已开放。

<div class="bh-actions bh-actions-center"><a class="bh-btn bh-btn-primary" href="https://discord.gg/QRHNKweYqS">加入 Zhiban Community</a></div>

服务器内目前包括：

- **#welcome** — 社区介绍、官网和 GitHub 入口；
- **#announcements** — BestHistory 官方版本与产品公告；
- **#general** — 社区自由交流；
- **best-history** — 提问、反馈、功能建议、Bug 报告和使用分享。
