# Seguridad

[← BestHistory](README.md) · [Todos los idiomas](../LANGUAGES.md)

No publiques vulnerabilidades de seguridad o privacidad en un Issue público si contienen datos sensibles.

Contacto: **besthistory@126.com**

No envíes exportaciones reales de historial privado, contraseñas, tokens, claves privadas, secretos de pago ni copias completas salvo que se soliciten expresamente mediante un canal de seguimiento seguro.
