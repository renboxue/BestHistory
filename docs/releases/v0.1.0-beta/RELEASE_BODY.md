# BestHistory v0.1.0 Beta

BestHistory 的第一个公开 Beta 已经可以下载。它是一款以“网站”为中心、本地优先的浏览历史整理工具。

The first public BestHistory Beta is now available. BestHistory is a local-first, website-centered browser history organizer.
