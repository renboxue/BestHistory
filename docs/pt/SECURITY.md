# Segurança

[← BestHistory](README.md) · [Todos os idiomas](../LANGUAGES.md)

Não publique vulnerabilidades de segurança ou privacidade em Issue público se o relato incluir dados sensíveis.

Contato: **besthistory@126.com**

Não envie exportações reais de histórico privado, senhas, tokens de autenticação, chaves privadas, segredos de pagamento ou backups completos, a menos que sejam solicitados explicitamente por um canal seguro.
