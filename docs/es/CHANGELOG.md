# Cambios

## v1.0.0 — 2026-08-27

BestHistory v1.0.0 es la primera versión oficial. Su publicación en Chrome Web Store llegará muy pronto.

- Historial organizado por sitio web, no por una lista interminable de páginas
- Búsqueda por dominios, títulos, etiquetas y notas
- AI Recall convierte recuerdos vagos en hipótesis de búsqueda local
- Organización con IA y sugerencias de etiquetas
- Private Mode con cifrado local y captura opcional de incógnito
- Copia / restauración en un solo archivo con combinación segura
- Inicio con Google y código por correo
- 30 días de Pro Trial para cuentas nuevas

- Paddle Live billing: $2.99/month, $24.99/year, $59.99 one-time Lifetime.
- Local-first privacy disclosures updated for optional AI processing.
- Chrome Web Store Limited Use and production policy documentation added.
- Client version metadata and lightweight server compatibility configuration added.
- Overlay/modal layering and background scroll-through fixed.

v0.1.0 Beta established the website-first history model, Private Mode, backup/restore, account entitlement model and 18-language interface.
