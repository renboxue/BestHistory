# BestHistory 中文使用指南

这些文章围绕真实问题来写：**标签页太多怕关掉、忘记以前用过的网站，以及不希望私密记录出现在日常历史列表里。**

## 放心关闭不用一直开着的标签页

### [Chrome 标签页太多不敢关？如何关闭后仍能找回网站](/zh-CN/guides/close-tabs-without-losing-websites/)
了解 Chrome 自带历史、收藏夹、会话保存与 BestHistory 的区别，不必为了记住网站而一直开着几十个标签页。

## 私人保险箱与加密浏览历史

### [如何给浏览历史加密码？使用本地加密的私人保险箱](/zh-CN/guides/encrypted-private-browser-history/)
了解普通历史、无痕窗口与 Pro 私密模式的不同，明确哪些记录可以加密保留、哪些不能保证隐藏。

## 找回以前访问过的网站

### [怎么搜索很久以前的 Chrome 历史记录](/zh-CN/guides/search-old-chrome-history/)
如果只记得大概用途、主题或某些模糊关键词，可以从 Chrome 自带搜索开始，再利用网站聚合、标签、备注和页面标题进一步缩小范围。

### [怎么找回以前访问过、但已经忘记名字的网站](/zh-CN/guides/find-website-you-visited-before/)
当你只记得“以前用过一个做某件事的网站”，但域名、标题和日期都忘了时，可以采用怎样的找回思路。

### [为什么浏览历史管理器应该先显示网站，而不是页面](/zh-CN/guides/chrome-history-manager/)
同一个网站几十条页面访问挤在历史记录里时，为什么“先按网站聚合”会更接近真实的回忆方式。
