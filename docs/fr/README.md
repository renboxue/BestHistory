> **v1.0.0** — BestHistory v1.0.0 est la première version officielle. Sa publication sur le Chrome Web Store arrive bientôt.

BestHistory est un gestionnaire d'historique Chrome / Chromium axé sur la confidentialité. Il regroupe d'abord l'historique par site, puis permet de rechercher, étiqueter, annoter, épingler, protéger, sauvegarder et retrouver des sites.

## v1.0.0

- Historique organisé par site plutôt qu'une longue liste de pages
- Recherche dans domaines, titres, tags et notes
- AI Recall transforme un souvenir vague en hypothèses de recherche locale
- Organisation IA et suggestions de tags
- Private Mode chiffré localement et capture incognito optionnelle
- Sauvegarde / restauration en un fichier avec fusion sûre
- Connexion Google et code e-mail
- 30 jours de Pro Trial pour les nouveaux comptes

## Local-first + AI

Conçu local-first : la base complète de l'historique, les données Private Mode et les sauvegardes ne sont pas envoyées au serveur de compte. Uniquement lorsque vous lancez volontairement une fonction IA, les données limitées nécessaires sont envoyées au serveur et au fournisseur IA. Voir Confidentialité pour les champs exacts.
