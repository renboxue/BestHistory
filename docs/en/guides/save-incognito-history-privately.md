# How to save incognito history privately when you choose to

Incognito mode is intentionally designed not to keep ordinary local browsing history after the private window closes. That is useful when you do not want a browsing session preserved.

Sometimes, however, you may want a different behavior: **keep the history for yourself, but keep it out of the ordinary browser-history list.**

## Incognito permission must be explicit

Chrome does not automatically allow extensions to run in incognito windows. The user must explicitly enable the permission for each extension.

BestHistory cannot turn that permission on by itself.

## BestHistory Private Mode

BestHistory Pro Private Mode can optionally capture incognito visits after you explicitly allow the extension to run in incognito. Those private URLs, page titles and visit records are stored in encrypted form on the local device rather than mixed into the normal website list.

When Private Mode is locked, the private sites and pages are not shown directly.

## This is not the same as making incognito “more anonymous”

Saving private history is about **your own local record keeping**. It does not make a browsing session invisible to websites, networks, employers, internet providers or other systems outside the browser.

Use the feature only when preserving those visits is what you actually want.

## Why this can be useful

The idea is simple: some history is useful enough that you do not want to forget it, but private enough that you do not want it sitting beside ordinary browsing history.
