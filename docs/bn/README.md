BestHistory একটি privacy-first Chrome / Chromium history manager। এটি আগে সাইট অনুযায়ী history গোষ্ঠীবদ্ধ করে, তারপর search, tag, note, pin, private storage, backup এবং rediscovery সহজ করে।

## v1.0.0

- দীর্ঘ page list নয়, website-first history
- domain, page title, tag ও note-এ search
- AI Recall অস্পষ্ট স্মৃতিকে local search hypothesis-এ রূপ দেয়
- AI website organization ও tag suggestion
- local encryption সহ Private Mode এবং optional incognito capture
- এক ফাইল backup / restore ও safe merge
- Google sign-in এবং email code
- নতুন account-এর জন্য 30-day Pro Trial

## Local-first + AI

Local-first: সম্পূর্ণ browsing-history database, Private Mode data এবং backup file BestHistory account server-এ upload হয় না। শুধুমাত্র আপনি ইচ্ছাকৃতভাবে AI feature ব্যবহার করলে, সেই request-এর জন্য প্রয়োজনীয় সীমিত data server এবং AI provider-এ পাঠানো হয়। সঠিক field-এর জন্য Privacy Notice দেখুন।
