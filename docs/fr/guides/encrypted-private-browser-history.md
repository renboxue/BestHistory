# Protéger son historique de navigation par mot de passe

Certains sites méritent d'être conservés, sans forcément apparaître à côté de vos visites quotidiennes. Supprimer l'historique n'est pas toujours la bonne réponse : vous souhaitez parfois **garder une trace personnelle tout en limitant l'accès à cette trace**.

## Historique normal, navigation privée et coffre : trois usages différents

L'historique classique de Chrome permet de retrouver des pages consultées. Une fenêtre de navigation privée, elle, évite normalement de conserver l'historique local de cette session après sa fermeture.

Le **mode privé de BestHistory Pro** répond à un autre besoin : conserver certains sites dans une zone chiffrée de votre appareil, distincte de la liste habituelle de BestHistory.

## Que protège le mode privé ?

- Les URL, titres et visites ajoutés au mode privé sont enregistrés dans une base locale chiffrée.
- Vous définissez un mot de passe pour déverrouiller cette liste.
- Lorsque le coffre est verrouillé, son contenu n'apparaît pas directement dans la liste ordinaire de BestHistory.
- Le mot de passe privé et les enregistrements privés déchiffrés ne sont pas envoyés au serveur de compte BestHistory.

**Important :** cela n'efface pas automatiquement les traces qui pourraient exister dans l'historique intégré à Chrome, un autre logiciel ou une sauvegarde.

## Peut-on conserver ses propres visites en navigation privée ?

Chrome ne conserve normalement pas ces visites dans l'historique ordinaire une fois la fenêtre privée fermée.

BestHistory Pro peut, si vous le souhaitez, enregistrer des visites privées dans son coffre, **uniquement après avoir autorisé explicitement l'extension à fonctionner en mode navigation privée** dans les paramètres de Chrome. Cela ne permet pas de récupérer rétroactivement d'anciennes sessions.

## Ce coffre ne rend pas anonyme

Le chiffrement local de certains enregistrements n'empêche pas les sites visités, les fournisseurs d'accès ou les administrateurs réseau d'observer des informations sur votre navigation. Si vous ne voulez conserver aucune trace d'une session privée, n'activez pas son enregistrement optionnel.

Le mode privé est inclus dans **BestHistory Pro**. Les nouveaux comptes disposent actuellement de 30 jours d'essai Pro ; les fonctions de base de l'historique restent gratuites sans inscription.
