# FAQ

[← BestHistory](README.md) · [Tutte le lingue](../LANGUAGES.md)

## Serve un account?
No. Le funzioni locali principali funzionano senza account. L’account serve soprattutto per i diritti Pro / Trial.

## BestHistory carica la mia cronologia?
No. Il server account non memorizza cronologia, URL, titoli, etichette, note, ricerche o dati privati.

## Cosa succede dopo la prova Pro?
Le funzioni Pro diventano non disponibili, ma i dati privati già cifrati restano sul dispositivo e non vengono eliminati. Tornando Pro puoi accedervi di nuovo.

## `.bhbackup` è uno snapshot completo del browser?
No. È un formato per trasferire e fondere in sicurezza i dati BestHistory tra installazioni, dispositivi o browser. Non riporta Chrome a uno stato passato.

## Perché il permesso incognito è separato?
Chrome richiede l’autorizzazione esplicita dell’utente per ogni estensione. BestHistory non può abilitarlo al tuo posto.

## Il codice è open source?
No. Questo repository pubblico contiene informazioni, documentazione, feedback e Beta. Il codice dell’applicazione è proprietario.
