# BestHistory v0.1.0 Beta

Primera Beta pública de BestHistory.

BestHistory organiza el historial alrededor de **sitios web**, no como una lista interminable de páginas. Nació de un problema personal: mantener demasiadas pestañas y ventanas abiertas, fijar y guardar cosas solo por miedo a no volver a encontrar un sitio útil.

Esta Beta incluye agrupación automática por sitio, vistas Recientes/Más visitados/Nombre/Fijados, etiquetas personalizadas, nombres y notas, línea de tiempo plegable, búsqueda, Papelera, `.bhbackup`, 18 idiomas de interfaz, Modo privado Pro y captura cifrada opcional de incógnito con permiso explícito.

También corrige el problema por el que la lista de sitios y la línea de tiempo podían quedarse desactualizadas cuando BestHistory permanecía abierto durante mucho tiempo.

## Privacidad
BestHistory es local-first. El servidor no almacena historial, URLs, títulos, etiquetas, notas, búsquedas, registros privados, claves de cifrado ni contenido de `.bhbackup`.

## Instalación
Descarga `BestHistory-v0.1.0-beta-chrome.zip`, descomprímelo, abre `chrome://extensions/`, activa Modo desarrollador y usa “Cargar descomprimida”.
