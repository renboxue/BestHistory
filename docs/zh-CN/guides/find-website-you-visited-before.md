# 怎么找回以前访问过但已经忘记名字的网站

很多时候我们忘记的不是内容，而是**网站叫什么**。

你可能记得它能转换文件、查价格、生成图片、看某类资料，却完全不记得域名，也不记得是哪一天打开的。这时传统的按时间排列历史记录并不符合人的记忆方式。

## 先搜索任何还能记住的线索

在 Chrome 历史记录里尝试页面标题片段、域名片段、产品名或主题词。不要一开始就逐天翻日期，除非你真的记得访问时间。

## 把“网站”作为第一层

BestHistory 的核心思路是先把成千上万条页面访问聚合成“我用过哪些网站”。你可以看到最近访问、最常访问、网站名称、标签和备注，再进入某个网站查看它下面曾经访问过的具体页面。

这种方式更适合“我记得它大概是什么网站，但不记得具体页面”的情况。

## 找到之后给它加一句自己的描述

例如：

- 上次用来压缩 PDF 的网站
- 做儿童插画时找到的参考站
- 可以查历史价格的小工具

以后直接搜索这些自己会说的话，更容易再次找回来。
