# Chrome 历史记录管理器应该解决什么问题

Chrome 已经自带历史记录，所以一个额外的历史记录管理插件应该解决默认列表没有解决好的问题，而不只是换一套界面。

常见需求包括：

- 更容易搜索以前浏览过的网页；
- 不记得网页标题时还能找回网站；
- 把同一网站的大量页面访问聚合起来；
- 给重要网站加标签、备注和固定；
- 清理或删除不需要的历史；
- 导出和备份；
- 清楚说明浏览数据是否会上传服务器；
- 对特殊的私密历史提供更细的控制。

BestHistory 更偏向其中的“**重新找回网站**”：先按照网站聚合，再保留网站下面的具体页面，并提供搜索、标签、备注、时间线、固定、废件箱和本地备份。

如果你的主要痛点是“我明明以前用过一个很好用的网站，但现在怎么也想不起名字”，这种网站优先的方式会比单纯的页面时间线更接近实际记忆。
