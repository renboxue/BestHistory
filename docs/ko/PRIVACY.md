# BestHistory 개인정보 보호 안내

_최종 업데이트: 2026-08-20_

[← BestHistory](README.md) · [모든 문서 언어](../LANGUAGES.md)

BestHistory는 로컬 우선 방식의 브라우저 기록 정리 확장 프로그램입니다.

## 브라우징 데이터
방문 기록, URL, 페이지 제목, 사이트 메타데이터, 태그, 메모, 검색 입력, 비공개 모드 기록은 사용자 기기에서 처리되며 BestHistory 계정 서버로 업로드되지 않습니다.

## 계정 및 권한 데이터
로그인하면 BestHistory는 계정을 식별하고 Free / Trial / Pro 권한을 확인합니다. 계정 ID, 이메일과 인증 메타데이터, 선호 UI 언어, 체험/회원/구독 상태와 유효기간, 향후 유료 구독을 위한 결제 제공자 식별자가 포함될 수 있습니다.

## 비공개 모드
비공개 URL, 제목, 방문 데이터는 기기에서 암호화됩니다. 비공개 비밀번호와 복호화된 비공개 데이터는 BestHistory 서버로 전송되지 않습니다.

## 백업 파일
백업은 로컬에서 생성되며 BestHistory가 자동 업로드하지 않습니다. 백업 안의 비공개 기록은 암호화 상태를 유지하지만 일반 기록 부분까지 파일 전체가 암호화되었다고 가정해서는 안 됩니다.

## 제3자 서비스
BestHistory는 현재 계정 인증/권한에 Supabase, 인증 이메일 전송에 Amazon SES를 사용합니다. 이 서비스는 계정과 이메일 전송에 필요한 데이터만 처리하며 사용자 브라우징 기록을 처리하거나 저장하지 않습니다.

## 데이터 삭제
확장 프로그램에서 로컬 BestHistory 데이터를 삭제할 수 있습니다. 로그아웃은 로컬 계정 세션을 제거하지만 로컬 기록 정리 데이터를 의도적으로 삭제하지 않습니다. 계정 삭제 흐름은 Beta 중 더 개선될 수 있습니다.
