# BestHistory 隐私说明

**最后更新：2026-08-27**

BestHistory 采用**本地优先**设计。本说明解释哪些数据留在设备上、哪些少量数据会因为账户、支付或 AI 功能离开设备，以及由谁处理。

## 本地数据

- 完整浏览历史数据库、普通历史记录、私密模式数据库、私密模式密码和 `.bhbackup` 备份文件默认保存在本机。
- BestHistory 不出售浏览数据，不将浏览数据用于个性化广告，也不向数据经纪商提供。

## 可选的 AI 数据处理

AI 功能是可选的，而且只有在用户主动使用时才会触发。

AI 回忆可能发送你的查询、已选择的现有标签，以及最多 12 条由本机筛选出的线索，例如域名和页面标题。

AI 整理网站可能分批发送域名、网站显示名、当前标签、最多 5 个近期页面标题、访问次数和页面数量。

BestHistory 不会为了这些 AI 功能发送完整浏览历史数据库、网页正文、私密模式记录或备份文件。

## 账户与第三方服务

BestHistory 当前可能使用以下服务：

- **Supabase**：认证、权益存储和 Edge Functions；
- **Google**：可选的 Google OAuth 登录；
- **Resend**：发送登录验证码和认证邮件；
- **Paddle**：作为 Merchant of Record 处理购买、税费、收据和订阅管理；
- **火山引擎 / 豆包 Ark**：处理 BestHistory 的 AI 请求。

BestHistory 可能保存账户 ID、邮箱、首选语言、试用/套餐状态、有效期以及支付平台标识等账户与权益数据。

BestHistory 不接收或保存完整银行卡信息。

## 私密模式

私密模式记录会在本机加密保存。

私密模式密码和解密后的私密网址、页面标题及私密浏览记录不会发送到 BestHistory 服务器。

## 支付

BestHistory Pro 当前提供：

- **$2.99 / 月**；
- **$24.99 / 年**；
- **$59.99 一次性终身版**。

Paddle 作为 Merchant of Record 处理结账、税费、收据、退款和订阅管理。Google 不是卖家。

BestHistory 不接收或保存完整支付卡信息。

## 数据共享与使用限制

只有在提供你选择的功能、完成认证或支付、保障服务安全，或遵守法律所必需时，BestHistory 才会向相关第三方服务发送必要数据。

BestHistory 不出售用户数据，也不把用户数据用于个性化广告。

## Chrome Web Store Limited Use

BestHistory 对从 Google API / Chrome 获取的数据，仅用于已公开说明且面向用户的功能，包括整理、搜索、私密管理、备份和重新找回浏览历史，以及相关账户和权益操作。

BestHistory 对 Google API 信息的使用将遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。

## 数据保留与删除

你可以在扩展中删除本地 BestHistory 数据。

退出登录会移除本地会话。如需删除服务器侧账户数据，可以联系：

**besthistory@126.com**

## 安全

BestHistory 服务之间传输的数据使用 HTTPS。

认证凭据、支付密钥和 AI 服务商密钥只保存在服务器端，不会打包进浏览器扩展。

## 联系方式

**besthistory@126.com**
