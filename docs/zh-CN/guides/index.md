# BestHistory 中文使用指南

这些文章不是单纯介绍功能，而是围绕真实问题来写：**已经忘了网站名字，怎么重新找到它？历史记录太多，怎么更快缩小范围？**

## 找回以前访问过的网站

### [怎么搜索很久以前的 Chrome 历史记录](/zh-CN/guides/search-old-chrome-history/)
如果只记得大概用途、主题或某些模糊关键词，可以从 Chrome 自带搜索开始，再利用网站聚合、标签、备注和页面标题进一步缩小范围。

### [怎么找回以前访问过、但已经忘记名字的网站](/zh-CN/guides/find-website-you-visited-before/)
当你只记得“以前用过一个做某件事的网站”，但域名、标题和日期都忘了时，可以采用怎样的找回思路。

### [为什么浏览历史管理器应该先显示网站，而不是页面](/zh-CN/guides/chrome-history-manager/)
同一个网站几十条页面访问挤在历史记录里时，为什么“先按网站聚合”会更接近真实的回忆方式。
