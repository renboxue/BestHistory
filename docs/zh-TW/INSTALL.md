# 安裝 BestHistory v1.0.0

BestHistory v1.0.0 面向 Chrome Web Store 發布。商店頁面上線後，請優先從 Chrome Web Store 安裝並自動更新。

## 安裝

1. 開啟 Chrome Web Store。
2. 搜尋 **BestHistory**。
3. 確認開發者與官網資訊後按「加到 Chrome」。
4. 安裝後可在擴充功能選單固定 BestHistory。
5. 點擊工具列圖示開啟主頁。

## 無痕視窗 / 私密模式

若要讓 BestHistory Pro 私密模式記錄無痕視窗存取，Chrome 要求你明確允許擴充功能在無痕模式執行。此權限為選用。

## 更新

Chrome Web Store 安裝版本由 Chrome 自動更新。重要升級前仍建議匯出 `.bhbackup`。
