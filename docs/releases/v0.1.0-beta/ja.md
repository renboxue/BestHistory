# BestHistory v0.1.0 Beta

BestHistory 最初の公開 Beta です。

BestHistory は、個々のページを延々と並べるのではなく「ウェブサイト」を中心に履歴を整理する拡張機能です。私自身、便利なサイトを二度と見つけられないのが怖くて、タブやウィンドウを大量に開き、固定やブックマークを増やしてしまうことがきっかけでした。

この Beta には、サイト単位の自動集約、最近/よく使う/名前/固定ビュー、カスタムタグ、サイト名とメモ、折りたたみタイムライン、サイト/ページ検索、ごみ箱、`.bhbackup`、18 UI 言語、Pro プライベートモード、明示許可後のシークレット訪問暗号化保存が含まれます。

また、BestHistory を長時間開いたままにしたときサイト一覧とタイムラインが新しい履歴へ更新されない問題を修正しました。

## プライバシー
BestHistory はローカルファーストです。サーバーは閲覧履歴、URL、タイトル、タグ、メモ、検索、プライベート記録、暗号鍵、`.bhbackup` 内容を保存しません。

## インストール
`BestHistory-v0.1.0-beta-chrome.zip` をダウンロードして展開し、`chrome://extensions/` でデベロッパーモードを有効化、「パッケージ化されていない拡張機能を読み込む」からフォルダーを選択してください。
