> **v1.0.0** — BestHistory v1.0.0 è la prima versione ufficiale. La pubblicazione sul Chrome Web Store arriverà a breve.

BestHistory è un gestore della cronologia Chrome / Chromium orientato alla privacy. Raggruppa prima per sito e rende più semplice cercare, etichettare, annotare, fissare, proteggere, fare backup e ritrovare siti.

## v1.0.0

- Cronologia per sito invece di un elenco infinito di pagine
- Ricerca in domini, titoli, tag e note
- AI Recall trasforma ricordi vaghi in ipotesi di ricerca locale
- Organizzazione IA e suggerimenti di tag
- Private Mode con crittografia locale e acquisizione incognito opzionale
- Backup / ripristino in un file con fusione sicura
- Accesso Google e codice e-mail
- 30 giorni di Pro Trial per nuovi account

## Local-first + AI

Local-first: il database completo della cronologia, i dati Private Mode e i backup non vengono caricati sul server account. Solo quando usi volontariamente una funzione IA vengono inviati al server e al provider IA i dati limitati necessari. Vedi Privacy per i campi esatti.
