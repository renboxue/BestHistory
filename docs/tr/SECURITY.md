# Güvenlik

[← BestHistory](README.md) · [Tüm diller](../LANGUAGES.md)

Hassas veri içeren güvenlik veya gizlilik açıklarını herkese açık Issue içinde paylaşmayın.

İletişim: **besthistory@126.com**

Güvenli bir takip kanalında açıkça istenmedikçe gerçek özel geçmiş dışa aktarımları, parolalar, kimlik doğrulama tokenları, özel anahtarlar, ödeme sırları veya tam yedekler göndermeyin.
