# Chrome의 오래된 방문 기록을 검색해 이전 페이지 찾기

전에 방문한 사이트의 이름은 잊어도 어떤 일을 했는지는 기억할 수 있습니다. 남아 있는 기록에서 찾아보는 방법을 소개합니다.

## Chrome 기본 기록에서 검색하기

주소창에 <code>chrome://history/</code> 를 입력하세요. Windows/Linux에서는 Ctrl+H로 열 수도 있습니다. 제목, URL 또는 도메인의 일부를 검색합니다.

## 표현을 바꿔 검색하기

사이트 이름이 떠오르지 않으면 당시 했던 작업이나 글 주제로 검색해 보세요. Chrome의 기본 검색은 저장된 제목과 URL 중심이며 페이지 본문 전체 검색과는 다릅니다.

## 사이트별로 기록 묶기

BestHistory는 같은 사이트의 방문 기록을 모아 보여줍니다. 해당 사이트의 페이지를 살펴보고 메모와 태그를 추가해 검색 단서를 늘릴 수 있습니다.

## 기록이 사라진 경우

삭제되었거나 보관되지 않은 기록을 복구한다고 보장할 수 없습니다. 이전 백업, 북마크 또는 내보낸 파일이 있는지 확인하세요.
