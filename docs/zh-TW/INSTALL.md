# 在 Chrome 安裝 BestHistory Beta

[← BestHistory](README.md) · [所有文件語言](../LANGUAGES.md)

目前 Beta 透過 GitHub Release 提供，在正式進入 Chrome Web Store 前需要手動安裝。

下載：**https://github.com/renboxue/BestHistory/releases/tag/v0.1.0-beta**

檔案：`BestHistory-v0.1.0-beta-chrome.zip`

## 安裝
1. 解壓 ZIP 到一個之後會保留的資料夾。
2. 開啟 `chrome://extensions/`。
3. 開啟右上角 **開發人員模式**。
4. 點擊 **載入未封裝項目 / Load unpacked**。
5. 選擇剛才解壓後的 BestHistory 資料夾。
6. 如有需要，可在 Chrome 擴充功能選單中固定 BestHistory。
7. 點擊工具列圖示即可直接打開主頁面。

## 無痕視窗 / 私密模式
若希望 Pro 私密模式記錄無痕訪問，Chrome 要求使用者明確允許擴充功能在無痕模式中執行：在 `chrome://extensions/` → BestHistory 詳細資料 → 開啟 **允許在無痕模式中執行**。

此權限為可選，BestHistory 無法代替你自動開啟。

## 手動更新
新的 Beta 可能需要替換原本解壓的資料夾並重新載入擴充功能。測試早期版本前，建議先匯出 `.bhbackup`。
