> **v1.0.0** — BestHistory v1.0.0 — первый официальный релиз. Версия в Chrome Web Store появится в ближайшее время.

BestHistory — ориентированный на приватность менеджер истории Chrome / Chromium. Он сначала группирует историю по сайтам, а затем помогает искать, ставить теги, делать заметки, закреплять, хранить приватно, создавать резервные копии и находить сайты снова.

## v1.0.0

- История по сайтам вместо бесконечного списка страниц
- Поиск по доменам, заголовкам, тегам и заметкам
- AI Recall превращает смутное воспоминание в гипотезы локального поиска
- AI-организация и предложения тегов
- Локально зашифрованный Private Mode и опциональное сохранение инкогнито
- Один файл резервной копии / восстановления с безопасным объединением
- Вход Google и код по электронной почте
- 30 дней Pro Trial для новых аккаунтов

## Local-first + AI

Local-first: полная база истории, данные Private Mode и резервные копии не загружаются на сервер аккаунта. Только когда вы сознательно запускаете AI-функцию, ограниченные данные, необходимые для запроса, передаются серверу и AI-провайдеру. Точные поля указаны в политике конфиденциальности.

## BestHistory Pro

Pro: $2,99/месяц, $24,99/год или $59,99 единоразово Lifetime. Платёж обрабатывает Paddle; Google не является продавцом.

New BestHistory accounts receive a **30-day Pro Trial** before paid access is required for Pro-only features.

После появления v1.0.0 в Chrome Web Store устанавливайте из магазина. Публичный репозиторий содержит документацию и поддержку, а не закрытый исходный код приложения.
