## 먼저, 왜 BestHistory를 만들었는지

BestHistory는 제가 개인 개발자로서 제 실제 불편을 해결하려고 만든 작은 도구입니다.

며칠 전에 분명 아주 유용한 사이트를 썼는데 다시 필요할 때 이름이 생각나지 않았습니다. “어떤 사이트에서 봤다”는 것만 기억나고 정확한 페이지는 떠오르지 않을 때도 많았습니다. 다시 못 찾을까 봐 탭과 창을 많이 열어 둔 채로 두고, 자주 쓰는 사이트는 고정하고, 중요한 것은 북마크에 넣었습니다. 시간이 지나면 기록, 고정 탭, 북마크, 닫기 무서운 페이지가 모두 쌓이지만, 정작 예전에 썼던 사이트 하나를 찾는 일은 여전히 어렵습니다.

그러다 깨달았습니다. 제가 원한 것은 더 예쁜 “방문 기록 목록”이 아니었습니다.

사람이 실제로 기억하는 방식에 더 가까운 정리가 필요했습니다.

**페이지 제목이나 방문 날짜는 잊어도, “어떤 사이트였는지”, “무엇에 썼는지”는 꽤 자주 기억합니다.**

그래서 BestHistory가 시작되었습니다.

> **“나중에 못 찾을까 봐” 열어 둔 탭을 안심하고 닫을 수 있게 하는 것.**  
> 정말 필요할 때 BestHistory가 다시 그곳을 찾아주는 것이 목표입니다.

아직 아주 초기의 개인 프로젝트입니다. 같은 고민을 조금이라도 해결한다면 정말 기쁠 것 같습니다. 무엇이 편한지, 무엇이 불편한지, 다음에는 어떤 문제를 해결해 주면 좋을지도 알려 주세요.

## 일반 브라우저 기록과 무엇이 다른가요?

### 1. 수만 개 페이지보다 먼저 “웹사이트”를 봅니다

브라우저 기본 기록은 모든 페이지 방문을 한 줄씩 쌓습니다. 같은 사이트에서 여러 페이지를 열면 기록 전체가 같은 사이트로 채워질 수 있습니다.

BestHistory는 먼저 기록을 **웹사이트 단위로 자동 묶습니다**. 최근 어떤 사이트를 썼는지, 어떤 사이트를 자주 쓰는지, 마지막 방문이 언제인지, 그 사이트 안에서 어떤 페이지를 열었는지 볼 수 있습니다.

### 2. 여러 정렬 방식으로 실제 자주 쓰는 사이트를 봅니다

- **최근 방문**
- **가장 자주 방문**
- **이름순**
- **고정**
- **미정리 / 휴지통 / 비공개 사이트** 등 상태별 보기

### 3. 나만의 태그로 분류합니다

다른 사람에게 “도구”인 사이트가 나에게는 “업무”일 수 있고, 동시에 “디자인”, “AI”, “나중에 다시 사용”일 수도 있습니다.

BestHistory는 **사용자 정의 태그**와 여러 태그를 지원합니다. 완벽한 분류표를 만드는 게 목적이 아니라, 시간이 지난 뒤 “대충 무엇에 쓰던 사이트였지?” 정도만 기억날 때 다시 찾을 수 있는 단서를 하나 더 만드는 것입니다.

### 4. 같은 사이트를 접어 보여 주는 깔끔한 타임라인

“어제 오후에 무엇을 보고 있었지?”처럼 시간 순서로 돌아보고 싶을 때도 있습니다.

BestHistory 타임라인은 같은 사이트에서 연속해서 연 페이지를 한 그룹으로 접어 두고, 필요할 때만 펼칩니다.

<p align="center"><img src="../../assets/screenshots/timeline.webp" alt="BestHistory 접을 수 있는 타임라인" width="100%" /></p>
<p align="center"><sub>같은 사이트의 페이지를 묶어 두어, 제목 벽이 아니라 실제 탐색 흐름처럼 볼 수 있습니다.</sub></p>

### 5. “나만 알아보면 되는” 설명을 사이트에 남깁니다

사이트 공식 이름만으로는 무엇에 썼는지 기억나지 않을 때가 있습니다. 그래서 직접 이름, 메모, 설명을 붙일 수 있습니다.

> “지난번 PDF를 이미지로 바꿨던 사이트”
>
> “어린이 일러스트 참고로 찾았던 곳”
>
> “과거 가격을 확인하는 작은 도구”

이런 내 말도 나중에 검색할 수 있습니다. 공식 제목보다 실제 기억과 더 잘 맞을 때가 있습니다.

## 비공개 모드: 기억은 하고 싶지만 다른 사람에게 보이고 싶지 않은 기록

어떤 사이트는 “기록을 남기기 싫은 것”이 아니라, 일반 기록에 섞여 다른 사람이 쉽게 보지 않았으면 하는 것일 수 있습니다.

**비공개 모드(Pro)** 는 비공개 URL, 페이지 제목, 방문 기록을 기기 안에서 암호화해 저장합니다. 설정한 비공개 비밀번호를 입력해야 확인할 수 있습니다.

사용자가 명시적으로 시크릿 모드 실행을 허용하면, 시크릿 창의 방문도 암호화해 저장할 수 있습니다. 일반 사이트 목록에는 섞이지 않고, 비공개 모드가 잠긴 동안에는 직접 표시되지 않습니다.

> **일반 기록에 남겨 두기 불편한 사이트도 BestHistory가 조용히 기억할 수 있습니다.**

비공개 데이터는 기기에 남으며 서버는 비공개 URL, 제목, 기록, 비밀번호를 저장하지 않습니다.

## 검색, 고정, 휴지통

BestHistory 검색은 도메인뿐 아니라 사이트, 태그, 메모, 페이지 제목도 활용합니다. 사이트 이름을 완전히 잊어도, 예전에 그곳에서 본 내용이나 직접 남긴 설명을 기억하면 다시 찾을 가능성이 있습니다.

자주 쓰는 사이트는 고정할 수 있고, 당장은 보고 싶지 않은 사이트는 바로 삭제하지 않고 **휴지통**에 둘 수 있습니다. 나중에 복원하거나 영구 삭제할 수 있습니다.

---

## 백업, 복원, 브라우저 간 이동

BestHistory 정리 데이터는 기본적으로 로컬에 저장됩니다. 하나의 `.bhbackup` 파일로 다른 PC, 다른 설치, 다른 브라우저로 옮기고 병합할 수 있습니다.

복원은 현재 데이터를 통째로 덮지 않고 안전 병합 방식으로 동작합니다. 비공개 데이터는 백업 안에서도 암호화 상태를 유지하며 원래 비밀번호가 필요합니다.

> 현재 “브라우저 간 동기화”는 로컬 백업 파일을 통한 이동과 병합을 뜻합니다. 전체 브라우징 기록을 클라우드로 올려 실시간 동기화하는 방식이 아닙니다.

BestHistory를 먼저 **로컬 우선** 도구로 만들고 싶기 때문입니다.

## 개인정보, Free와 Pro

BestHistory 서버는 방문 기록, URL, 페이지 제목, 태그, 메모, 검색, 비공개 기록, 암호화 키, `.bhbackup` 내용을 저장하지 않습니다.

로그인하면 서버는 주로 계정, 인증, Free / Trial / Pro 권한을 처리합니다. 자세한 내용은 [PRIVACY.md](PRIVACY.md)를 참고해 주세요.

핵심 로컬 기능은 **로그인하지 않아도 계속 사용할 수 있습니다**. Beta 기간에는 신규 가입 계정에 현재 **30일 Pro 체험**이 제공되며, 현재 가장 중요한 Pro 기능은 비공개 모드입니다.

## 이제 시작입니다

BestHistory를 만들게 된 가장 큰 이유는 “탭을 닫으면 다시 못 찾을 것 같아서 계속 열어 두는” 습관이었습니다.

지금은 닫은 웹사이트를 다시 찾는 데 도움을 줄 수 있습니다. 앞으로도 같은 핵심 문제를 중심으로, 불필요한 탭을 더 안심하고 닫고 실제로 사용한 웹사이트를 더 편하게 정리하는 방법을 고민하고 싶습니다.

도움이 된다면 ⭐ Star, Issue, 또는 평소 기록·북마크·수많은 탭을 어떻게 관리하는지 알려 주세요. 공개하기 어려운 의견은 **besthistory@126.com** 으로 보내셔도 됩니다.

공개 Issue에는 비공개 URL, 비밀번호, 비공개 기록, 전체 백업 파일 같은 민감한 정보를 포함하지 말아 주세요.
