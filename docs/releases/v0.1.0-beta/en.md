# BestHistory v0.1.0 Beta

The first public BestHistory Beta.

BestHistory is a browser-history extension organized around **websites** rather than a giant list of individual page visits. It grew out of a problem I had myself: I kept too many tabs and windows open, pinned things and bookmarked things simply because I was afraid I would never find a useful website again.

This Beta includes:

- automatic website-first history aggregation;
- Recent / Most visited / Name / Pinned views;
- custom tags;
- custom website names and notes;
- a collapsible timeline grouped by website;
- website and page search;
- Wastebasket and permanent deletion;
- local `.bhbackup` backup, restore and cross-browser transfer;
- 18 interface languages;
- Pro Private Mode with locally encrypted private websites and visits;
- optional encrypted capture of incognito visits after explicit browser permission;
- a fix for stale website/timeline data when BestHistory remains open for a long time.

## Privacy

BestHistory is local-first.

The BestHistory server does not store your browsing history, visited URLs, page titles, tags, notes, searches, private browsing records, Private Mode encryption keys or `.bhbackup` contents.

## Install

1. Download `BestHistory-v0.1.0-beta-chrome.zip`
2. Extract it into a folder you will keep
3. Open `chrome://extensions/`
4. Enable **Developer mode**
5. Click **Load unpacked**
6. Select the extracted folder
