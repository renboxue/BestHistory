> **v1.0.0** — BestHistory v1.0.0 已正式发布，Chrome Web Store 商店版本即将上线。

BestHistory 是一款隐私优先的 Chrome / Chromium 浏览历史管理器。它先按网站聚合历史，再让你搜索、打标签、写备注、置顶、私密保存、备份，并重新找回以前用过的网站。

## v1.0.0

- 以网站为中心整理历史，而不是面对成千上万条页面记录
- 搜索域名、页面标题、标签和自己的备注
- AI 回忆：把模糊记忆扩展成本地历史搜索线索
- AI 整理网站：根据有限网站信息建议标签
- 私密模式：本地加密，并可选择记录无痕窗口访问
- 单文件备份 / 恢复与安全合并
- Google 登录与邮箱验证码登录
- 新账户 30 天 Pro Trial

## Local-first + AI

本地优先：完整浏览历史数据库、私密模式数据和备份文件不会上传到 BestHistory 账户服务器。只有当你主动使用 AI 功能时，完成该次 AI 请求所必需的少量数据才会发送到服务器和 AI 服务商；具体字段见隐私说明。
