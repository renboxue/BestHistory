> **v1.0.0** — BestHistory v1.0.0은 첫 정식 릴리스입니다. Chrome Web Store 버전은 곧 공개됩니다.

BestHistory는 개인정보 보호를 우선하는 Chrome / Chromium 방문 기록 관리자입니다. 기록을 먼저 웹사이트별로 묶고 검색, 태그, 메모, 고정, 비공개 저장, 백업, 재발견을 쉽게 합니다.

## v1.0.0

- 페이지 목록 대신 웹사이트 중심으로 기록 정리
- 도메인, 페이지 제목, 태그, 메모 검색
- AI Recall로 모호한 기억을 로컬 검색 단서로 확장
- AI 웹사이트 정리와 태그 제안
- 로컬 암호화 Private Mode와 선택적 시크릿 기록 저장
- 단일 파일 백업 / 복원 및 안전한 병합
- Google 로그인과 이메일 코드 로그인
- 신규 계정 30일 Pro Trial

## Local-first + AI

로컬 우선 설계입니다. 전체 방문 기록 데이터베이스, Private Mode 데이터, 백업 파일은 BestHistory 계정 서버에 업로드되지 않습니다. 사용자가 AI 기능을 직접 실행한 경우에만 해당 요청에 필요한 제한된 데이터가 서버와 AI 제공업체로 전송됩니다. 정확한 항목은 개인정보 처리방침을 확인하세요.
