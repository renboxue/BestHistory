# BestHistory v0.1.0 Beta

BestHistory 的第一个公开 Beta 版本。

BestHistory 是一个以“网站”为中心整理浏览历史的浏览器扩展。它来自我自己长期使用浏览器时的一个真实困扰：因为怕以后找不到曾经用过的网站，我总是开着很多标签页和窗口，还不断固定、收藏，最后反而越来越难找。

这个 Beta 目前主要包含：

- 按网站自动聚合浏览历史
- 最近访问 / 最常访问 / 名称排序 / 已固定等多种查看方式
- 自定义标签
- 网站名称与备注
- 按网站折叠的时间线
- 网站和页面搜索
- 废件箱与永久删除
- 本地 `.bhbackup` 备份、恢复与跨浏览器迁移
- 18 种界面语言
- Pro 私密模式：本机加密保存私密网站和访问记录
- 在用户明确授权后，可自动加密保存无痕窗口中的访问记录
- 修复 BestHistory 长时间保持打开时“我的网站”和“时间线”不能及时同步最新历史的问题

## 隐私

BestHistory 采用本地优先设计。

BestHistory 服务器不会保存你的浏览历史、访问网址、页面标题、标签、备注、搜索内容、私密浏览记录、私密模式加密密钥或 `.bhbackup` 备份内容。

## 安装

1. 下载 `BestHistory-v0.1.0-beta-chrome.zip`
2. 解压到一个长期保留的文件夹
3. 打开 Chrome 的 `chrome://extensions/`
4. 开启“开发者模式”
5. 点击“加载已解压的扩展程序”
6. 选择刚才解压后的文件夹
