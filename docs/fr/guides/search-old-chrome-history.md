# Rechercher un ancien historique Chrome et retrouver ses pages

Vous vous souvenez de ce qu'un site permettait de faire, mais plus de son nom ? Voici comment exploiter les traces qui existent encore dans l'historique.

## Utiliser d'abord l'historique intégré

Saisissez <code>chrome://history/</code> dans Chrome (ou Ctrl+H sous Windows/Linux). Recherchez un mot du titre, une partie de l'adresse ou le domaine du site.

## Essayer différentes pistes

Si le nom du site vous échappe, essayez le type d'outil ou le sujet de l'article. Chrome recherche principalement les titres et adresses enregistrés, pas tout le contenu de chaque page.

## Regrouper les visites par site

BestHistory présente d'abord les sites consultés et permet ensuite d'explorer leurs pages. Les notes et étiquettes apportent des moyens supplémentaires de les retrouver.

## Comprendre les limites

Aucun gestionnaire d'historique ne garantit la récupération des visites supprimées ou non conservées. Vérifiez aussi vos anciennes sauvegardes et vos favoris.
