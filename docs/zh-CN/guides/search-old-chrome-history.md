# 怎么搜索很久以前的 Chrome 历史记录

Chrome 自带的 `chrome://history/` 适合你还记得网页标题、域名或关键词的时候。但如果已经过去几周甚至几个月，只记得“以前用过一个做 PDF 的网站”或者“某个网站里看过这篇内容”，按时间翻历史记录会非常慢。

## 先用 Chrome 自带搜索

打开 `chrome://history/`，输入你还能记住的标题片段、网站域名、产品名或主题词。如果大概记得访问日期，再结合时间范围缩小结果。

## 记得网站、不记得页面时，按网站找更自然

普通历史记录把每次页面访问都平铺出来。同一个网站打开几十个页面，就会出现几十条记录。

BestHistory 会先按照**网站**聚合浏览历史，再在网站下面保留你访问过的具体页面。这样你可以先回答“我以前用过哪些网站”，再进入某个网站继续找具体页面。

## 给未来的自己留下备注

网站官方标题不一定是你以后会搜索的词。给网站写一句自己的备注，例如“上次用来把 PDF 转成图片”，往往比官方页面标题更符合真实记忆。

BestHistory 支持搜索网站、域名、标签、备注和页面标题，让同一条历史有更多找回路径。
