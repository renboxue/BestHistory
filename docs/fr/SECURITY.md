# Sécurité

[← BestHistory](README.md) · [Toutes les langues](../LANGUAGES.md)

Ne publiez pas de vulnérabilité de sécurité ou de confidentialité dans un Issue public si elle contient des données sensibles.

Contact : **besthistory@126.com**

N’envoyez pas de vrais exports d’historique privé, mots de passe, jetons d’authentification, clés privées, secrets de paiement ou sauvegardes complètes, sauf demande explicite via un canal de suivi sécurisé.
