# BestHistory 退款政策

**最后更新：2026-08-28**

BestHistory 由 **Beijing Boxue Zhiban Software Development Studio** 运营。BestHistory Pro 的付款由 **Paddle** 处理，Paddle 是本交易的 Merchant of Record（记录商户）。

## 退款申请

退款由 Paddle 根据其退款政策以及用户所在国家或地区适用的消费者保护法律处理。本政策不会限制法律强制赋予消费者的任何权利。

你可以通过以下方式申请退款或获得购买帮助：

- 使用 Paddle 付款收据邮件中的购买或支持链接；
- 使用 Paddle 的买家支持或订阅管理服务；
- 联系 BestHistory：**besthistory@126.com**，并提供足以帮助我们定位交易的购买信息。

Paddle 当前公开的买家退款政策可查看：[paddle.com/legal/refund-policy](https://www.paddle.com/legal/refund-policy)。

## 订阅与取消

BestHistory Pro 的月付和年付方案会自动续费，直到用户取消为止。

你可以通过 Paddle 客户门户，或 Paddle 付款邮件中的管理链接取消订阅。通常情况下，取消会在当前已付费周期结束后停止后续续费。

取消订阅本身不等于自动退还已经完成的付款。

## 终身版

BestHistory Lifetime 为一次性付款，不会自动续费。终身版的退款资格同样由 Paddle 根据其退款政策和适用的消费者法律处理。

## 退款成功后的权益处理

如果 Paddle 完成退款，与该笔退款交易对应的 BestHistory Pro 权益可能会被撤销或调整，以与实际付款状态保持一致。

## 如果是产品问题

如果你认为扣款有误、已经付款但无法使用 Pro，或遇到明显产品故障，可以先联系 **besthistory@126.com**。我们会尽量先确认问题，并在需要时协助你通过 Paddle 处理退款。
