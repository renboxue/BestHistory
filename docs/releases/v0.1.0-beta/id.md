# BestHistory v0.1.0 Beta

Beta publik pertama BestHistory.

BestHistory mengatur riwayat browsing berdasarkan **situs web**, bukan sebagai daftar halaman tanpa akhir. Ini lahir dari masalah pribadi: saya membiarkan terlalu banyak tab dan window terbuka, menyematkan dan membookmark sesuatu hanya karena takut tidak bisa menemukan situs berguna lagi.

Beta ini mencakup grouping situs otomatis, tampilan Terbaru/Paling sering/Nama/Disematkan, tag kustom, nama dan catatan situs, timeline lipat, pencarian, Tong Sampah, `.bhbackup`, 18 bahasa UI, Mode Privat Pro, dan capture incognito terenkripsi opsional setelah izin eksplisit.

Bug yang membuat daftar situs dan timeline tidak ikut memperbarui riwayat terbaru saat BestHistory dibiarkan terbuka lama juga sudah diperbaiki.

## Privasi
BestHistory local-first. Server tidak menyimpan riwayat, URL, judul, tag, catatan, pencarian, data privat, kunci enkripsi, atau isi `.bhbackup`.

## Instalasi
Unduh `BestHistory-v0.1.0-beta-chrome.zip`, ekstrak, buka `chrome://extensions/`, aktifkan Developer mode dan pilih “Load unpacked”.
