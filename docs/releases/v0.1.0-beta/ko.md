# BestHistory v0.1.0 Beta

BestHistory의 첫 공개 Beta입니다.

개별 페이지 목록 대신 **웹사이트**를 중심으로 브라우징 기록을 정리합니다. 저 역시 유용한 사이트를 다시 못 찾을까 봐 탭과 창을 많이 열고, 고정하고, 북마크를 계속 늘렸던 경험에서 시작했습니다.

이번 Beta에는 웹사이트 자동 집계, 최근/자주/이름/고정 보기, 사용자 태그, 사이트 이름과 메모, 접기 타임라인, 사이트/페이지 검색, 휴지통, `.bhbackup`, 18개 UI 언어, Pro 비공개 모드, 명시적 허용 후 시크릿 방문 암호화 저장이 포함됩니다.

또한 BestHistory를 장시간 열어 둔 경우 사이트와 타임라인이 최신 기록으로 갱신되지 않던 문제를 수정했습니다.

## 개인정보
BestHistory는 로컬 우선입니다. 서버는 브라우징 기록, URL, 제목, 태그, 메모, 검색, 비공개 기록, 암호화 키, `.bhbackup` 내용을 저장하지 않습니다.

## 설치
`BestHistory-v0.1.0-beta-chrome.zip`을 다운로드해 압축 해제하고 `chrome://extensions/`에서 개발자 모드를 켠 뒤 “압축해제된 확장 프로그램을 로드합니다”를 선택하세요.
