# BestHistory v0.1.0 Beta

BestHistory-এর প্রথম public Beta।

BestHistory endless page list-এর বদলে browsing history-কে **website** কেন্দ্র করে organize করে। এটি আমার নিজের সমস্যা থেকে শুরু: useful site আবার না পাওয়ার ভয়ে অনেক tab/window খোলা রাখতাম, pin এবং bookmark করতে থাকতাম।

এই Beta-তে automatic site grouping, Recent/Most visited/Name/Pinned views, custom tags, site name এবং notes, collapsible timeline, search, Trash, `.bhbackup`, 18 UI languages, Pro Private Mode এবং explicit permission-এর পরে optional encrypted Incognito capture আছে।

BestHistory দীর্ঘ সময় খোলা থাকলে site list এবং timeline latest history-তে update না হওয়ার bug-ও ঠিক করা হয়েছে।

## Privacy
BestHistory local-first। Server history, URL, title, tag, note, search, private record, encryption key বা `.bhbackup` content store করে না।

## Install
`BestHistory-v0.1.0-beta-chrome.zip` download ও extract করুন, `chrome://extensions/` খুলুন, Developer mode চালু করুন এবং “Load unpacked” বেছে নিন।
