# Aviso de Privacidade do BestHistory

_Última atualização: 2026-08-20_

[← BestHistory](README.md) · [Todos os idiomas](../LANGUAGES.md)

O BestHistory é uma extensão local-first para organizar o histórico do navegador.

## Dados de navegação
Histórico, URLs visitadas, títulos, metadados de sites, etiquetas, notas, pesquisas e registros do Modo Privado são processados no dispositivo. Esses dados não são enviados ao servidor de contas do BestHistory.

## Conta e direitos
Se você entrar, o BestHistory usa a infraestrutura de conta para identificar a conta e determinar Free, Trial ou Pro. Isso pode incluir ID da conta, e-mail e metadados de autenticação, idioma preferido, status e validade de teste/assinatura e futuros identificadores do provedor de pagamento.

## Modo Privado
URLs privadas, títulos e visitas são criptografados no dispositivo. A senha privada e os dados privados descriptografados não são enviados ao servidor.

## Backups
Os backups são criados localmente e não são enviados automaticamente. Registros privados permanecem criptografados dentro do arquivo; não se deve presumir que todos os dados de histórico comum estejam criptografados como um todo.

## Serviços de terceiros
Atualmente usamos Supabase para autenticação e direitos, e Amazon SES para e-mails de autenticação. Eles processam apenas os dados necessários para conta e entrega de e-mail, não o histórico de navegação.

## Exclusão
Você pode apagar dados locais dentro da extensão. Sair da conta remove a sessão local, mas não apaga intencionalmente os dados locais de organização. Fluxos de exclusão de conta podem evoluir durante o Beta.
