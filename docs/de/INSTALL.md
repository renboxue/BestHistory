# Installation — BestHistory

Installieren Sie BestHistory aus dem offiziellen Chrome Web Store oder Firefox Add-ons. Prüfen Sie den Anbieter, fügen Sie die Erweiterung hinzu und öffnen Sie sie über die Symbolleiste. Store-Versionen werden normalerweise automatisch aktualisiert.

- [Für Chrome installieren](https://chromewebstore.google.com/detail/besthistory/ehcgfdgajgkkmelcjipahckmgjfdcajb)
- [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/besthistory/)

## Privater Verlauf

Für die optionale Aufzeichnung von Inkognito-Besuchen in Pro müssen Sie BestHistory in Chromes Erweiterungseinstellungen ausdrücklich für den Inkognitomodus zulassen.
