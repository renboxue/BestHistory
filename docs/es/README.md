> **v1.0.0** — BestHistory v1.0.0 es la primera versión oficial. Su publicación en Chrome Web Store llegará muy pronto.

BestHistory es un gestor de historial para Chrome / Chromium centrado en la privacidad. Agrupa primero por sitio web y permite buscar, etiquetar, anotar, fijar, guardar en privado, respaldar y redescubrir sitios.

## v1.0.0

- Historial organizado por sitio web, no por una lista interminable de páginas
- Búsqueda por dominios, títulos, etiquetas y notas
- AI Recall convierte recuerdos vagos en hipótesis de búsqueda local
- Organización con IA y sugerencias de etiquetas
- Private Mode con cifrado local y captura opcional de incógnito
- Copia / restauración en un solo archivo con combinación segura
- Inicio con Google y código por correo
- 30 días de Pro Trial para cuentas nuevas

## Local-first + AI

Diseño local-first: la base completa del historial, Private Mode y los archivos de copia no se suben al servidor de cuenta. Solo al usar voluntariamente una función de IA se envían al servidor y al proveedor de IA los datos limitados necesarios para esa solicitud. Consulte Privacidad para los campos exactos.

## Install

Cuando v1.0.0 esté disponible en Chrome Web Store, instálalo desde la tienda. El repositorio público contiene documentación y soporte, no el código fuente propietario.
