# 브라우저 방문 기록에 비밀번호를 설정해 보관하는 방법

다시 방문하고 싶은 사이트이지만 평소 방문 기록 목록에는 보이고 싶지 않을 때가 있습니다. 모든 기록을 지우는 것보다는 **필요한 기록을 따로 보관하고 접근을 제한하는 방법**이 더 적합할 수 있습니다.

## 일반 방문 기록과 시크릿 모드는 다릅니다

Chrome의 일반 방문 기록은 이전 페이지를 다시 찾는 데 유용합니다. 시크릿 창은 보통 창을 닫은 뒤 해당 세션의 방문 기록을 일반 로컬 기록에 남기지 않습니다.

반면 **BestHistory Pro 비공개 모드**는 선택한 비공개 URL, 페이지 제목, 방문 기록을 일반 BestHistory 목록과 분리해 **기기에 로컬로 암호화 저장**합니다.

## 비공개 보관함에서 할 수 있는 일

- 비공개 항목을 기기에 암호화된 형태로 저장합니다.
- 사용자가 설정한 비밀번호로 잠금을 해제해야 내용을 볼 수 있습니다.
- 잠겨 있는 동안 일반 BestHistory 사이트 목록에 비공개 기록이 직접 나타나지 않습니다.
- 비공개 모드 비밀번호와 복호화된 기록은 BestHistory 계정 서버로 전송하지 않습니다.

**주의:** Chrome 자체 방문 기록, 다른 확장 프로그램, 동기화 서비스나 백업에 이미 남은 기록을 자동으로 지워 주는 기능은 아닙니다.

## 시크릿 창의 방문 기록도 남길 수 있나요?

원한다면 가능합니다. 사용자가 Chrome 확장 프로그램 설정에서 BestHistory의 **시크릿 모드 실행을 직접 허용**한 이후에만, Pro가 해당 방문 기록을 암호화된 비공개 공간에 보관할 수 있습니다. 허용 전에 저장되지 않은 과거 기록을 소급 복구할 수는 없습니다.

## 익명 브라우징을 보장하지는 않습니다

로컬 기록을 암호화한다고 해서 방문한 사이트나 인터넷 서비스 제공업체, 네트워크 관리자로부터 인터넷 활동이 감춰지는 것은 아닙니다. 기록을 전혀 남기고 싶지 않다면 시크릿 모드의 선택적 기록 기능을 켜지 마세요.

**비공개 모드는 Pro 기능**입니다. 신규 계정에는 현재 30일 Pro 체험이 제공되며, 기본 방문 기록 정리 기능은 로그인 없이 무료로 사용할 수 있습니다.
