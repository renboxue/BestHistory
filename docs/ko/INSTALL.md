# Chrome에 BestHistory Beta 설치

[← BestHistory](README.md) · [모든 문서 언어](../LANGUAGES.md)

Chrome Web Store 정식 등록 전에는 GitHub Releases에서 Beta를 배포합니다.

다운로드: **https://github.com/renboxue/BestHistory/releases/tag/v0.1.0-beta**

파일: `BestHistory-v0.1.0-beta-chrome.zip`

1. ZIP을 계속 보관할 폴더에 압축 해제합니다.
2. `chrome://extensions/`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭합니다.
5. 압축 해제한 BestHistory 폴더를 선택합니다.
6. 필요하면 Chrome 확장 메뉴에서 고정합니다.
7. 도구 모음의 BestHistory 아이콘을 클릭하면 메인 화면이 열립니다.

## 시크릿 / 비공개 모드
시크릿 방문을 비공개 모드에 저장하려면 `chrome://extensions/` → BestHistory 세부정보 → **시크릿 모드에서 허용**을 켜야 합니다. 선택 권한이며 BestHistory가 대신 켤 수 없습니다.

## 수동 업데이트
새 Beta는 기존 압축 해제 폴더 교체와 확장 프로그램 재로드가 필요할 수 있습니다. 초기 버전 업데이트 전 `.bhbackup`을 권장합니다.
