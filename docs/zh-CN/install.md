# 安装 BestHistory v1.0

BestHistory v1.0 面向 Chrome Web Store 发布。商店页面上线后，请优先通过 Chrome Web Store 安装和自动更新。

## 安装步骤

1. 打开 Chrome Web Store。
2. 搜索 **BestHistory**。
3. 确认开发者和官网信息后，点击“添加至 Chrome”。
4. 安装后可以在扩展菜单中固定 BestHistory。
5. 点击浏览器工具栏里的 BestHistory 图标即可打开主页面。

## 无痕窗口与私密模式

如果你希望 BestHistory Pro 的私密模式记录无痕窗口中的访问，Chrome 要求你手动授权扩展在无痕窗口中运行：

1. 打开 `chrome://extensions/`。
2. 找到 BestHistory，进入“详细信息”。
3. 开启“在无痕模式下启用”。

这是可选权限，BestHistory 无法代替你自动开启。

## 更新

通过 Chrome Web Store 安装的版本会由 Chrome 自动更新。

重要升级前，仍建议先导出一份 `.bhbackup` 本地备份。
