# Como pesquisar o histórico antigo do Chrome e reencontrar páginas

Você lembra para que servia um site, mas esqueceu seu nome? Veja como procurar pistas no histórico que ainda está disponível.

## Use primeiro a busca do Chrome

Digite <code>chrome://history/</code> na barra de endereços (ou Ctrl+H no Windows/Linux). Pesquise partes do título, URL ou domínio.

## Experimente outros termos

Se esqueceu o nome, tente a atividade ou o assunto da página. A busca do histórico não equivale a pesquisar o conteúdo completo de todos os sites visitados.

## Organize as visitas por site

O BestHistory reúne páginas sob cada site. Você pode abrir visitas antigas e adicionar etiquetas e notas pessoais para facilitar buscas futuras.

## Se o histórico não estiver mais lá

Visitas removidas ou que o navegador não guardou não podem ser recuperadas de forma garantida. Confira também favoritos, backups ou exportações anteriores.
