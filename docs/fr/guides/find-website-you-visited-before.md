# Retrouver un site visité il y a plusieurs mois sans connaître son nom

Vous vous souvenez de ce qu'un site permettait de faire, mais plus de son nom ? Voici comment exploiter les traces qui existent encore dans l'historique.

## Partir des indices qui restent

Ouvrez <code>chrome://history/</code>. Essayez un fragment du titre, un domaine ou l'usage du site, par exemple « convertir un PDF » ou « graphique de prix ». Variez les mots : l'historique de Chrome ne recherche pas automatiquement dans tout le texte des pages visitées.

## Retrouver le site avant la page

Si vous avez ouvert de nombreuses pages sur un même site, la liste chronologique peut devenir confuse. BestHistory regroupe les visites par site, puis permet d'examiner les pages associées.

## Créer ses propres indices

Une fois le site retrouvé, ajoutez une étiquette ou une note comme « outil utilisé pour convertir des PDF ». Ces mots personnels seront plus faciles à rechercher plus tard.

## Savoir ce qui est impossible

BestHistory ne peut pas recréer une visite supprimée ou jamais enregistrée. Il sert à explorer et organiser plus facilement l'historique encore disponible.
