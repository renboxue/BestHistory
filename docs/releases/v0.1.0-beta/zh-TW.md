# BestHistory v0.1.0 Beta

BestHistory 第一個公開 Beta 版本。

這是一個以「網站」為中心整理瀏覽歷史的擴充功能。它來自我自己的困擾：因為怕以後找不到曾經用過的網站，我總是開著太多分頁和視窗，還一直固定、收藏，最後反而更難整理。

此 Beta 包含：
- 自動按網站聚合歷史
- 最近 / 最常 / 名稱 / 已固定視圖
- 自訂標籤、網站名稱與備註
- 按網站折疊的時間軸
- 網站與頁面搜尋
- 廢件箱與永久刪除
- 本機 `.bhbackup` 備份、恢復與跨瀏覽器遷移
- 18 種介面語言
- Pro 私密模式，本機加密私密網站與訪問紀錄
- 明確授權後可加密保存無痕訪問
- 修復 BestHistory 長時間開啟時網站和時間軸不會及時同步新歷史的問題

## 隱私
BestHistory 採用本機優先設計，伺服器不保存瀏覽歷史、網址、標題、標籤、備註、搜尋、私密紀錄、私密模式金鑰或 `.bhbackup` 內容。

## 安裝
下載 `BestHistory-v0.1.0-beta-chrome.zip`，解壓後開啟 `chrome://extensions/`，啟用開發人員模式，點擊「載入未封裝項目」並選擇解壓後資料夾。
