# 이름이 기억나지 않는 예전에 방문한 웹사이트 찾는 방법

전에 방문한 사이트의 이름은 잊어도 어떤 일을 했는지는 기억할 수 있습니다. 남아 있는 기록에서 찾아보는 방법을 소개합니다.

## 기억나는 단서부터 검색하기

Chrome에서 <code>chrome://history/</code> 를 열어 페이지 제목 일부, 도메인 또는 사용했던 기능(예: PDF 변환)을 입력하세요. 한 단어로 안 나오면 다른 표현도 시도하세요. Chrome 기록 검색은 방문한 모든 페이지의 본문 전체를 검색하지는 않습니다.

## 페이지보다 사이트부터 찾기

한 사이트에서 여러 페이지를 열었다면 기록이 길어집니다. BestHistory는 방문 기록을 사이트별로 묶어 보여주고 해당 사이트의 개별 페이지를 나중에 확인하게 해 줍니다.

## 나만의 검색 단서 남기기

사이트를 찾은 뒤 'PDF를 이미지로 바꿨던 곳'처럼 메모나 태그를 남기면 이름을 다시 잊었을 때도 검색할 수 있습니다.

## 남아 있지 않은 기록은 복원할 수 없음

삭제되었거나 브라우저에 저장되지 않았던 방문 기록을 BestHistory가 새로 만들어 낼 수는 없습니다. 기존 기록을 더 쉽게 찾고 정리하는 도구입니다.
