# 閲覧履歴をパスワードで保護するには？

後でまたアクセスしたいサイトでも、通常の履歴一覧に並べたくないものがあります。すべて削除するのではなく、**自分のために保存しながら、普段の一覧とは分けて管理する**という選択肢があります。

## 通常の履歴・シークレットモード・保管庫の違い

Chromeの通常の履歴は、過去のページを探すのに便利です。一方、シークレットモードは終了後に通常のローカル閲覧履歴を残さないことを目的としています。

BestHistory Proのプライベートモードは別の用途です。自分が残したいプライベートなサイト情報を、通常のBestHistory一覧と分けて**端末上で暗号化して保存**します。

## BestHistory Proのプライベートモード

- プライベートなURL、ページタイトル、訪問記録を端末上の暗号化領域に保存します。
- 設定したパスワードでロックを解除して表示します。
- ロック中はBestHistoryの通常のサイト一覧にプライベートな記録を表示しません。
- 復号されたプライベート記録やプライベートモードのパスワードは、BestHistoryのアカウントサーバーへ送信しません。

ただし、**Chrome標準の履歴や他の拡張機能に既に残った情報が、自動で削除されるわけではありません**。必要に応じて別途確認してください。

## シークレットモードの履歴を保存したい場合

Chromeは通常、シークレットウィンドウを閉じるとその訪問履歴を保持しません。

BestHistory Proでは、ユーザーがChromeの拡張機能設定で**シークレットモードでの実行を明示的に許可**した場合に、訪問記録をプライベート領域へ保存する機能を選択できます。許可前の過去の訪問を後から復元することはできません。

## 匿名化ツールではありません

この保管庫は、ネットワーク管理者、接続先サイト、プロバイダーから通信を隠す機能ではありません。履歴を残したくないセッションでは、追加の記録機能を有効にしないでください。

**プライベートモードはPro機能です。** 新規アカウントには現在30日間のPro体験期間があります。通常の履歴整理はログイン不要で無料利用できます。
