# 如何给浏览历史加密码？把需要保留的私密记录放进保险箱

有些网站你确实想记住，但不希望它们和日常浏览过的网站混在一起。比如个人研究、敏感项目或者只想自己查看的网址。

把浏览历史全部删除并不是唯一办法。有时你真正需要的是：**记录仍然留着，但查看它需要额外的密码。**

## 普通历史、无痕浏览和私人保险箱，有什么区别？

| 方式 | 适合的需求 | 需要注意 |
| --- | --- | --- |
| Chrome 普通历史 | 找回浏览器保存过的网页 | 可以在 Chrome 自带历史页面里查看 |
| 无痕窗口 | 不希望该次会话进入普通本机历史 | 窗口关闭后，浏览器通常不会保留它的历史 |
| BestHistory Pro 私密模式 | 单独加密保存自己想保留的私密网站记录 | 不等于网络匿名，也不会自动抹掉其他地方的记录 |

## BestHistory 私人保险箱能做什么？

Pro 私密模式会在本机对私密网址、页面标题和访问记录进行加密保存，并用你设置的密码解锁查看。

保险箱锁定时，私密内容不会直接出现在 BestHistory 的普通网站列表里。私密密码及解密后的私密浏览记录不会发送到 BestHistory 账户服务器。

但要注意：这**不代表** Chrome 自带历史记录、其他扩展、同步服务或其他备份中的相关内容会自动删除。如果你希望这些地方也不保留记录，需要分别了解它们的行为。

## 能保存无痕窗口关闭后的历史吗？

可以选择开启这一能力，但必须由用户本人授权。

Chrome 默认不允许扩展在无痕窗口中运行。只有在 `chrome://extensions` 中找到 BestHistory，进入详情并手动启用“在无痕模式下启用”，再按产品提示使用私密模式后，相关记录才有机会进入独立加密记录区。

这不是对所有旧无痕历史的追溯恢复，也不能在未授权前补录过去的访问。

## 私人保险箱能保证匿名吗？

不能。私人保险箱解决的是**本机私密记录的保存与查看**问题，不会隐藏网站、网络服务商、单位网络等其他系统可能看到的活动。

如果你根本不希望某次无痕会话被保留下来，就不要为这次会话启用额外的记录功能。

## 什么人适合使用？

- 想保留一些不适合出现在日常历史列表里的私人网站；
- 希望查找自己过去访问过的私密网址，同时用密码限制随手查看；
- 希望在明确授权下，给部分无痕浏览记录留一个仅在本机管理的加密入口。
