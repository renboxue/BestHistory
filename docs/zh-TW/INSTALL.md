# 安裝 — BestHistory

從官方 Chrome Web Store 或 Firefox Add-ons 安裝 BestHistory，核對開發者後加入擴充功能，再從瀏覽器工具列開啟。商店安裝通常會自動更新。

- [加到 Chrome](https://chromewebstore.google.com/detail/besthistory/ehcgfdgajgkkmelcjipahckmgjfdcajb)
- [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/besthistory/)

## 私密歷史

若想讓 Pro 私密模式記錄無痕視窗的造訪，必須由你在 Chrome 擴充功能設定中明確允許無痕模式執行。
