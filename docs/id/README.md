> **v1.0.0** — BestHistory v1.0.0 adalah rilis resmi pertama. Versi Chrome Web Store akan segera hadir.

BestHistory adalah pengelola riwayat Chrome / Chromium yang mengutamakan privasi. Riwayat dikelompokkan per situs terlebih dahulu, lalu Anda dapat mencari, memberi tag, catatan, pin, menyimpan secara privat, mencadangkan, dan menemukan kembali situs.

## v1.0.0

- Riwayat berbasis situs, bukan daftar halaman tanpa akhir
- Cari domain, judul halaman, tag, dan catatan
- AI Recall mengubah ingatan samar menjadi hipotesis pencarian lokal
- Pengorganisasian AI dan saran tag
- Private Mode terenkripsi lokal dan tangkapan incognito opsional
- Backup / restore satu file dengan merge aman
- Login Google dan kode email
- Pro Trial 30 hari untuk akun baru

## Local-first + AI

Local-first: database riwayat lengkap, data Private Mode, dan file backup tidak diunggah ke server akun. Hanya ketika Anda sengaja memakai fitur AI, data terbatas yang diperlukan untuk permintaan itu dikirim ke server dan penyedia AI. Lihat Kebijakan Privasi untuk kolom yang tepat.

## BestHistory Pro

Pro: $2,99/bulan, $24,99/tahun, atau $59,99 sekali bayar Lifetime. Pembayaran diproses Paddle; Google bukan penjual.

New BestHistory accounts receive a **30-day Pro Trial** before paid access is required for Pro-only features.

## Install

Saat v1.0.0 tersedia di Chrome Web Store, instal dari store. Repositori publik berisi dokumentasi dan dukungan, bukan kode sumber aplikasi proprietary.
